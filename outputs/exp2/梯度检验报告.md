# 扩展② 自动求导梯度检验报告

> 生成脚本：`experiments/exp2_grad_check.py` ｜ 数值梯度：中心差分（eps=1e-05）｜ 判定阈值：最大相对误差 < 1e-05

## 一、检验方法：中心差分原理

对以数组 `x` 为自变量的标量函数 `f(x)`（这里即“前向计算到标量损失”），第 i 个分量的数值梯度按**中心差分**计算：

```
g_i ≈ [ f(x + ε·e_i) − f(x − ε·e_i) ] / (2ε),   ε = 1e-5
```

与反向传播得到的**解析梯度** `a_i` 逐元素比较相对误差：

```
rel_i = |a_i − n_i| / max(1e-8, |a_i| + |n_i|)
```

当**所有输入、所有元素**的最大 rel < 1e-05 时判定该算子检验通过。

## 三、误差来源分析

1. **截断误差（O(ε²)）**：中心差分公式由泰勒展开截断而来，真实导数与差分值之差约为 (ε²/6)·f'''(ξ)。ε=1e-5 时该项约为 1e-11 量级，是本检验的主要误差来源之一。
2. **舍入误差（O(u/ε)）**：浮点减法相消使差分分子仅保留约 u/ε 的相对精度（u 为机器精度）。ε 越小舍入误差越大，因此 ε 不能盲目取小；总误差在 ε ≈ u^(1/3) 附近最小。
3. **不可导点**：relu 在 x=0、maxpool 在窗口内两值相等处不存在连续导数。本实验通过“输入远离 0（|x|≥0.2）”“逐窗口无放回采样（元素两两至少差 0.1）”规避不可导点/近平局，防止伪失败。
4. **数值稳定化路径**：softmax / CrossEntropy / BCEWithLogits 均采用减最大值等稳定化写法。这类写法与原始函数数学等价且处处光滑，不影响梯度检验，但避免了 exp 溢出带来的 inf/NaN。
5. **求和顺序差异**：解析梯度与数值梯度的浮点累加顺序不同，会引入 ~1e-16 量级的随机舍入差，远小于阈值。

## 四、为什么必须使用 float64

- float64 的机器精度 u ≈ 2.2×10⁻¹⁶，中心差分总误差最小的步长约为 ε ≈ u^(1/3) ≈ 6×10⁻⁶，恰好与本实验使用的 eps=1e-5 同量级，此时可把相对误差压到 **1e-10 ~ 1e-12**，足以暴露反向传播中的任何实现错误；
- 若用 float32（u ≈ 1.2×10⁻⁷），最优步长退化为 ~5×10⁻³，数值梯度噪声高达 1e-3 量级，比判定阈值 1e-5 还大，检验将失去分辨力；
- 因此契约规定 `Node` 内部数据统一转 `np.float64`（数据集可用 float32，进 Node 时自动转换），这正是为梯度检验服务的设定。
