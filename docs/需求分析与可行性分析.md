## 一、项目背景与目标

### 1.1 背景

深度学习框架（PyTorch / TensorFlow / Paddle）把"计算图构建、自动微分、算子实现、
优化器更新"等复杂机制封装在底层。直接调用高层 API 虽然方便，但学习者往往只记住
`model.fit()`，并不清楚一次训练迭代中前向如何建图、梯度如何沿链式法则回传、
卷积如何被展开成矩阵乘、Adam 的偏差修正究竟修正了什么。

本项目要求**从零实现一个迷你深度学习框架**，并用它完成经典 CNN 任务，
从而把"会用框架"推进到"理解并能造框架"。

### 1.2 项目目标

1. 实现一个纯 numpy、无自动微分库依赖的迷你框架 **MiniFlows**；
2. 框架需具备：节点/计算图、前向计算、反向传播、三种以上激活函数、
   MBGD 与 Adam 优化器、卷积、池化、线性层、损失函数、训练器；
3. 用该框架完成线性回归、逻辑回归、鸢尾花分类、MNIST 手写数字识别、
   DonkeyCar 自动驾驶（模拟赛道）五类应用；
4. 用 PyTorch 搭建同结构 LeNet-5 作为对照，验证自研实现的正确性与性能差距；
5. 完成五项可选扩展：计算图可视化、自动求导与梯度数值检验、异常训练分析、
   数据预处理模块、框架优化功能；
6. 形成需求分析、可行性分析、详细设计、测试报告与可复现实验产物。

### 1.3 与"优秀"评分标准对照

课程对"优秀"的要求是：在完成基础目标之上**至少三项改进**，认真分析框架的系统性功能，
给出需求分析与详细设计，并对疑难问题做可行性研究。本项目的对应关系如下：

| 评分要求 | 本项目落实 |

## 二、需求分析

### 2.1 功能需求

| 编号 | 需求 | 验收标准 | 实现位置 |
|---|---|---|---|
| F1 | 计算图节点 | 节点保存值、梯度、父节点与反向闭包；支持运算符重载与梯度累加 | `miniflows/graph.py` |
| F2 | 前向计算 | 任意 DAG 前向可执行，形状正确 | 全部算子测试 |
| F3 | 反向传播 | 从损失节点一次 `backward()` 得到全部参数梯度；`x*x+x` 的梯度为 `2x+1` | `tests/test_core.py` |
| F4 | 激活函数 ≥3 种 | ReLU、Sigmoid、Tanh，另加 Softmax | `miniflows/ops.py` |
| F5 | 优化器 | MBGD（可选动量）、Adam（含偏差修正） | `miniflows/optim.py` |
| F6 | 卷积 | `(N,C,H,W)` 输入，任意 `stride/padding`，与朴素实现逐元素一致 | `ops.conv2d`（im2col） |
| F7 | 池化 | 最大池化/平均池化，反向梯度路由正确 | `ops.maxpool2d/avgpool2d` |
| F8 | 层与容器 | Linear/Conv2D/Pool/Flatten/激活/Dropout/Sequential | `miniflows/layers.py` |
| F9 | 损失函数 | MSE、BCEWithLogits（数值稳定）、CrossEntropy | `miniflows/losses.py` |
| F10 | 训练器 | 小批量、训练/评估模式、验证指标、回调、早停 | `miniflows/trainer.py` |
| F11 | 线性回归 | 学到 w≈3、b≈2，MSE 接近噪声方差 | `applications/linear_regression.py` |
| F12 | 逻辑回归 | 二分类测试准确率 ≥95% | `applications/logistic_regression.py` |
| F13 | 鸢尾花分类 | 两层 MLP 测试准确率 ≥90% | `applications/iris.py` |
| F14 | MNIST 分类 | 快速模式（8000/2000，3 轮）≥90% | `applications/mnist.py` |
| F15 | DonkeyCar | 合成赛道图像 → 转向角，MAE < 0.1 | `applications/donkeycar.py` |
| F16 | PyTorch 对照 | 同结构、同数据、同超参，准确率差距 <2 个百分点 | `pytorch_benchmark/train_lenet.py` |
| F17 | 计算图可视化 | 纯 matplotlib 输出 DAG 图片，节点显示算子与形状 | `visualization.draw_computation_graph` |
| F18 | 梯度数值检验 | 全部算子相对误差 <1e-5，输出 Markdown 报告 | `autodiff.gradient_check` |
| F19 | 异常训练分析 | 四类现象各有对照实验、图表与原因分析 | `experiments/exp3_*.py` |
| F20 | 数据预处理 | 标准化/MinMax、one-hot、分层划分、DataLoader、平移增强 | `miniflows/data.py` |
| F21 | 框架优化功能 | 动量、Dropout、L2、早停、学习率调度、保存/加载一致 | `miniflows/utils.py` |
| F22 | 一键复现 | 所有脚本在项目根目录直接运行，产物落入 `outputs/` | 全部脚本 |

### 2.2 非功能需求

| 类别 | 要求 | 本项目措施 |
|---|---|---|
| 正确性 | 梯度与数值梯度一致；卷积与朴素实现一致 | 中心差分检验；朴素 conv2d 对拍；端到端任务准确率 |
| 易用性 | 接口简单，仿 Keras/PyTorch | `Sequential([...])` + `Trainer.train()`；60 行即可完成一次训练 |
| 性能 | MNIST 快速模式在普通 CPU 上可接受 | im2col 卷积、批量矩阵乘；实测 3 轮约 11 秒 |
| 可复现性 | 固定随机种子后结果可重复 | `common_setup.init_env(seed)` + 各脚本显式 seed |
| 可维护性 | 模块边界清晰、接口稳定 | 先写《API 契约》再并行开发；统一中文注释 |
| 可扩展性 | 新算子/新层/新优化器可插拔 | `Node._backward` 闭包 + `Layer` 基类 + `Optimizer` 基类 |
| 可移植性 | Windows/Linux 均可运行 | 纯 Python + numpy，无编译扩展 |
| 可观测性 | 训练过程与异常可诊断 | history 曲线、梯度范数、计算图可视化、梯度检验报告 |

### 2.3 约束与假设

- 运行环境为 CPU（GPU 版 PyTorch 可用但对照实验固定 CPU，保证公平）；
- 核心数值统一 float64：数值梯度检验需要 ~1e-10 精度，float32 不够；
- 允许使用 torchvision/sklearn 仅作为**数据加载**来源，框架本身不依赖它们；
- DonkeyCar 无真车与摄像头，采用"合成赛道图像 → 转向角"的离线监督学习，
  并以简化运动学闭环仿真验证（见 4.3）；
- MNIST 快速模式使用类别均衡子集，用于课堂演示；`--full` 可跑全量。

## 三、可行性分析

### 3.1 技术可行性

**（1）自动微分的实现可行性。** 反向模式自动微分只需两件事：
① 每个算子在前向时记录输入与输出；② 注册一个把输出梯度映射为输入梯度的闭包。
由于神经网络的计算图是 DAG，从损失节点做一次拓扑排序后逆序执行闭包，即可在
O(V+E) 时间内得到所有参数的梯度。MiniFlows 的 `Node` 仅保存
`data/grad/parents/_backward`，实现约 300 行，已在 34 项算子检验中通过
（最大相对误差 2.98e-9）。

**（2）卷积的计算可行性。** 直接七重循环在 numpy 中不可接受。采用 im2col：
把每个 `(C,KH,KW)` 感受野展平成一行，得到 `(N·OH·OW, C·KH·KW)` 矩阵，
一次 `@` 完成全部输出通道计算；反向用 col2im 把列梯度散射回输入（重叠处累加）。
实测 LeNet 结构在 8000 样本、batch=64 下每轮约 4 秒，满足课堂演示需求。

**（3）数值稳定性可行性。** Sigmoid/BCE/Softmax/CrossEntropy 均采用"减最大值"或
"e^{-|z|}"的稳定写法；Adam 分母加 `eps`；梯度爆炸实验证明不加裁剪时 4 轮内溢出，
加裁剪后损失从 34.25 稳定降到 0.648，说明数值风险可控且可诊断。

**（4）计算图绘制的可行性。** 不引入 graphviz 依赖：对 DAG 做 BFS 求深度，
按深度分层、同层均匀分布，用 matplotlib 的 `FancyArrowPatch` 画边、
`FancyBboxPatch` 画节点框、`annotate` 标注算子与形状。输出为 PNG，无需浏览器
或本地安装 Graphviz，跨平台稳定。

**（5）与 PyTorch 对照的可行性。** 两边使用完全相同的 LeNet 结构
（Conv1-6@5 → Pool → Conv2-16@5 → Pool → FC120 → FC84 → FC10，44,426 参数）、
相同数据子集、相同超参（Adam lr=1e-3，batch=64，3 轮）。实测准确率
92.85%（MiniFlows）vs 93.05%（PyTorch），差值 0.20 个百分点；耗时 10.9s vs 1.4s，
差距主要来自 numpy 的解释器开销与 float64，符合预期。

### 3.2 经济可行性

- 全部软件开源：Python、numpy、matplotlib、PyTorch 均免费；
- 无 GPU 硬性要求：MNIST 快速模式在 CPU 上 11 秒完成；全量模式亦仅需数分钟；
- 数据免费公开：MNIST（LeCun 等，CC BY-SA 3.0 类许可）、鸢尾花（UCI）；
- 开发成本：本项目约 6,000 行代码（含注释与文档），单人或小组一学期内可完成；
- 运行成本：单次完整复现（全部实验 + 测试）低于 10 分钟 CPU 时间。

### 3.3 操作可行性

- 安装：`pip install -r requirements.txt`，无编译步骤；
- 运行：所有脚本在项目根目录 `python applications/xxx.py` 直接执行；
- 学习成本：API 与 Keras 高度相似，新用户 10 分钟可读懂
  `Sequential([Linear(2,1)])` 示例；
- 可观测：每个实验自动保存图片与 Markdown 报告到 `outputs/`，无需额外工具；
- 中文支持：`common_setup.init_env()` 统一处理 Windows 控制台 UTF-8 与
  matplotlib 中文字体，避免乱码。

### 3.4 法律与数据可行性

- MNIST 为公开手写数字数据集，广泛用于教学研究；
- 鸢尾花数据集来自 UCI，公开可用；
- DonkeyCar 部分使用的赛道图像由脚本即时合成，不涉及真实道路数据与隐私；
- 项目代码为原创实现，第三方库仅以依赖形式调用，未复制其源码。

### 3.5 风险分析与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 数值梯度检验因不可导点误报 | 误判框架有 bug | 输入远离 ReLU 0 点、maxpool 用无重复随机输入、统一 float64 |
| numpy 广播把 `(N,1)` 与 `(N,)` 组合成 `(N,N)` | 损失/梯度错误且不报错 | BCE 内显式把标签 reshape 为 `(N,1)`；测试覆盖该场景 |
| 深层网络梯度消失/爆炸 | 训练不收敛 | 提供 He/Xavier 初始化、梯度裁剪、Adam、学习率调度 |
| CNN 训练过慢 | 课堂演示超时 | im2col + 子集快速模式；实测每轮 4 秒 |
| MNIST 下载失败 | 首次运行中断 | torchvision → 官方镜像 urllib → 本地缓存三级降级 |
| 计算图节点过多导致图片不可读 | 可视化失败 | `max_nodes` 截断、只画离输出最近的节点、分层布局 |
| 保存/加载参数错位 | 推理结果不一致 | 按参数名对号入座；断言 max_diff == 0 |

### 3.6 可行性研究结论

从技术、经济、操作、法律四个维度看，本项目均可行：

1. **技术上有成熟路径且已被验证**——框架核心 34 项梯度检验通过，
   MNIST/PyTorch 对照准确率仅差 0.2 个百分点；
2. **成本极低**——纯 CPU、纯开源、单次全量复现 <10 分钟；
3. **操作简单**——仿 Keras API，一条命令一个实验，产物自动归档；
4. **风险可控**——主要数值风险均有明确对策并在实验中验证。

因此，项目具备立项与实施条件，可以按计划完成全部基础任务与五项扩展。
