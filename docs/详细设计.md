## 一、总体架构

MiniFlows 采用**分层 + 单向依赖**设计：上层只依赖下层，核心框架只依赖 numpy。

```
┌─────────────────────────────────────────────────────────────────────┐
│  应用层  applications/                                              │
│  线性回归 · 逻辑回归 · 鸢尾花分类 · MNIST 手写数字 · DonkeyCar       │
├─────────────────────────────────────────────────────────────────────┤
│  实验层  experiments/          │  对照层  pytorch_benchmark/        │
│  计算图 · 梯度检验 · 异常训练  │  PyTorch LeNet-5（仅用于公平对比）  │
│  预处理 · 框架优化             │                                    │
├─────────────────────────────────────────────────────────────────────┤
│  训练设施层  miniflows/trainer.py · utils.py · data.py              │
│  批量迭代 · train/eval 模式 · 回调 · 早停 · 学习率调度 · 数据划分    │
├─────────────────────────────────────────────────────────────────────┤
│  模型层  miniflows/layers.py · losses.py · optim.py                 │
│  Sequential · Linear · Conv2D · Pool · 激活 · MSE/BCE/CE · MBGD/Adam│
├─────────────────────────────────────────────────────────────────────┤
│  计算层  miniflows/ops.py · autodiff.py                             │
│  matmul · im2col 卷积 · 池化 · 广播 · 归约 · 数值梯度              │
├─────────────────────────────────────────────────────────────────────┤
│  图与自动微分层  miniflows/graph.py                                 │
│  Node · 拓扑排序 · 反向传播 · 运算符重载 · 梯度累加                 │
├─────────────────────────────────────────────────────────────────────┤
│  基础层  numpy（数组与 BLAS 矩阵乘） + matplotlib（可视化）          │
└─────────────────────────────────────────────────────────────────────┘
```

**依赖原则**

1. `graph.py` 只依赖 numpy；
2. `ops.py` 依赖 `graph`，不依赖 `layers/losses/optim`；
3. `layers/losses/optim` 依赖 `ops` 与 `graph`；
4. `trainer/utils/data/visualization` 依赖上述模块；
5. 应用与实验脚本只调用公开 API，不直接改 `Node` 内部字段（除梯度裁剪等诊断实验）。

## 三、核心数据结构

### 3.1 `Node`

| 字段 | 类型 | 含义 |
|---|---|---|
| `data` | `np.ndarray(float64)` | 前向值，标量用 0 维数组表示 |
| `grad` | `np.ndarray \| None` | 反向梯度，形状与 `data` 相同 |
| `requires_grad` | `bool` | 是否为可训练参数（或依赖参数） |
| `parents` | `list[Node]` | 输入节点，构成 DAG 边 |
| `op_name` | `str` | 产生该节点的算子名（如 `MatMul`、`Conv2D`） |
| `name` | `str \| None` | 参数名/调试名 |
| `_backward` | `callable \| None` | 反向闭包：读取 `self.grad`，向 `parents` 的 `grad` 累加 |

关键设计：

- **梯度累加而非覆盖**：实现 `a.grad += ...`，保证同一节点被多次使用时梯度不丢；
  用户需在每个训练步前调用 `optimizer.zero_grad()`（与 PyTorch 语义一致）。
- **运算符重载**：`__add__/__sub__/__mul__/__truediv__/__matmul__` 及反射版本，
  标量与 ndarray 自动包装为常量节点。
- **`__array_priority__ = 1000`**：解决 `np.ones((2,2)) - node` 被 numpy 逐元素
  广播成 object 数组的问题，使 numpy 让出运算权给 `Node.__rsub__`。
- **`backward()`**：从当前节点做只含 `requires_grad=True` 子图的拓扑排序，
  逆序调用 `_backward`；种子梯度缺省为 1。

### 3.2 `Layer` / `Sequential`

```python
class Layer:
    W, b = None, None          # 复参层才持有
    def forward(self, x): ...
    def params(self):          # 返回 [W, b]
    def named_params(self):    # [('W', W), ('b', b)]
    def train_mode(self, flag): ...
```

`Sequential` 依次前向；`named_params()` 生成全局唯一名字：
层有 `name` 属性时用 `name.W`，否则用 `layer{i}.W`（`i` 为层在容器中的索引）。
`summary(input_shape)` 逐层前向推断形状并统计参数量（中文表格）。

### 3.3 `Trainer`

```python
Trainer(model, loss_fn, optimizer, task='classification'|'regression')
  .train(X, y, X_val=None, y_val=None, epochs=10, batch_size=32,
         shuffle=True, callbacks=None, l2_fn=None, verbose=True) -> history
  .evaluate(X, y) -> (loss, accuracy_or_mse)
  .predict(X) -> ndarray
  .predict_classes(X) -> ndarray
```

`history` 固定包含 `train_loss/val_loss/val_acc/lr` 四个列表；
`callbacks` 为 `fn(state) -> bool`，返回 True 触发早停。

## 四、关键算法设计

### 4.1 计算图构建与拓扑排序

前向时每个算子新建 `Node` 并设置 `parents=[a,b]`；无全局图对象，图由引用隐式表达。
反向执行顺序必须保证"父节点晚于子节点处理"，即对 DAG 做后序 DFS：

```
visited = set(); order = []
def dfs(n):
    if n in visited or not n.requires_grad: return
    visited.add(n)
    for p in n.parents: dfs(p)
    order.append(n)
dfs(root)
for n in reversed(order): n._backward()
```

复杂度 O(V+E)；只有 `requires_grad=True` 的子图参与，常量分支被剪枝。

### 4.2 反向传播与梯度累加

对 `y = f(x)`，若已知 `dL/dy = g`，则 `dL/dx += J_f(x)^T g`。
每个算子的闭包只需实现局部雅可比与向量的乘积：

| 算子 | 前向 | 反向（局部） |
|---|---|---|
| `add(a,b)` | `a+b` | `da += g`, `db += g`（广播轴求和） |
| `mul(a,b)` | `a*b` | `da += g*b`, `db += g*a` |
| `matmul(A,B)` | `A@B` | `dA += g@Bᵀ`, `dB += Aᵀ@g` |
| `relu(x)` | `max(0,x)` | `dx += (x>0)*g` |
| `sigmoid(x)` | `σ(x)` | `dx += σ(1-σ)*g` |
| `conv2d` | im2col 矩阵乘 | `dW = colᵀ·g`, `dx = col2im(g·Wᵀ)` |
| `maxpool2d` | 窗口取最大 | `dx[argmax] += g`，其余为 0 |

`unbroadcast(g, shape)` 把因 numpy 广播而扩张的梯度沿被扩张的轴求和，
还原到原形状，保证 `W:(in,out)`、`b:(out,)` 的梯度形状正确。

### 4.3 im2col 卷积

输入 `x:(N,C,H,W)`、权重 `W:(F,C,KH,KW)`、步长 `s`、填充 `p`：

1. 对 `x` 四周补零，得到 `(N,C,H+2p,W+2p)`；
2. 输出空间尺寸 `OH=(H+2p-KH)//s+1`，`OW` 同理；
3. 每个 `(n,oh,ow)` 取 `(C,KH,KW)` 感受野展平成一行 →
   列矩阵 `col:(N·OH·OW, C·KH·KW)`；
4. 权重展平 `Wmat:(C·KH·KW, F)`；
5. `out = col @ Wmat + b`，再 reshape 回 `(N,F,OH,OW)`。

反向：

- `dWmat = colᵀ @ g_flat`，`db = g` 在 `(N,OH,OW)` 上求和；
- `dcol = g_flat @ Wmatᵀ`，再用 col2im 把每行散射回补零后的 `dx`，
  重叠位置**累加**（这正是卷积反向需要的结果）；
- 最后去掉 padding 区域。

复杂度：前向从朴素 `O(N·F·OH·OW·C·KH·KW)` 的 Python 循环，
降为一次大型 BLAS 矩阵乘，配合 float64 在 CPU 上每轮 MNIST 约 4 秒。

### 4.4 池化反向

`maxpool2d` 前向记录每个窗口最大值的位置（或反向时重新比较）；
反向只把该位置的梯度置为 `g`，其余为 0。若窗口内有并列最大值，
按次梯度约定把梯度分给所有并列位置（数值检验时使用无重复随机输入避免歧义）。

`avgpool2d` 反向把 `g / (kh·kw)` 均分到窗口内每个位置。

### 4.5 数值稳定的交叉熵

对 `C` 类 logits `z`，标签 `y`：

```
m = max_c z_c
logp_c = z_c - m - log(Σ_j exp(z_j - m))
L = -mean(logp_y)
∂L/∂z = (softmax(z) - onehot(y)) / N
```

减最大值保证 `exp` 的参数 ≤0，不会上溢；`logsumexp` 保持精度。
BCEWithLogits 使用等价恒等式
`-[t·logσ(z)+(1-t)·log(1-σ(z))] = max(z,0) - z·t + log(1+e^{-|z|})`，
`e^{-|z|}∈(0,1]` 永不溢出。**特别注意**：当预测为 `(N,1)`、标签为 `(N,)` 时，
必须先把标签 reshape 成 `(N,1)`，否则 numpy 会广播成 `(N,N)` 的笛卡尔组合，
损失与梯度都会错误（本项目在 BCE 与 MSELoss 中都实测并修复了该问题；
DonkeyCar 严格评测第一次运行学不动，根因正是 MSELoss 的广播）。

### 4.6 Adam 优化器

```
m_t = β₁ m_{t-1} + (1-β₁) g_t
v_t = β₂ v_{t-1} + (1-β₂) g_t²
m̂_t = m_t / (1-β₁ᵗ),  v̂_t = v_t / (1-β₂ᵗ)
θ_t = θ_{t-1} - lr · m̂_t / (√v̂_t + ε)
```

`m/v` 与参数同形，`t` 每步加 1；`eps=1e-8` 防止除零。
更新直接写 `p.data -= ...`，不参与建图（否则会无限增长计算图）。

### 4.7 梯度数值检验

中心差分：`∂f/∂x_i ≈ (f(x+εe_i) - f(x-εe_i)) / (2ε)`，截断误差 O(ε²)、
舍入误差 O(u/ε)，float64（u≈2.2e-16）与 ε=1e-5 时最优误差约 1e-11。

判据采用**相对误差**：

```
rel = |g_analytic - g_numeric| / max(1e-8, |g_analytic| + |g_numeric|)
```

全部元素 `rel < 1e-5` 判定通过，避免绝对误差在梯度量级大时误判。

## 五、扩展项设计

### 5.1 扩展① 计算图可视化

- 输入：任意 `Node`（通常是损失）；
- 布局：BFS 计算每个节点的"到输出距离"作为层号，`x = 深度`，同层 `y` 均匀分布；
- 绘制：`FancyBboxPatch` 节点框 + `FancyArrowPatch` 有向边；
  参数节点、常量节点、算子节点、损失节点使用不同颜色；
- 规模控制：节点数 > `max_nodes` 时只保留离输出最近的节点，避免"毛线团"；
- 输出：PNG，无 graphviz 依赖。演示见 `outputs/exp1/`。

### 5.2 扩展② 自动求导与梯度检验

- `gradient_check(f, arrays)`：把输入包装为 `Node`，前向 + `backward()` 得解析梯度；
  再用 `numerical_gradient` 得数值梯度；逐元素比较并返回报告；
- `check_model_gradients(model, x, loss_fn, y)`：遍历 `named_params()`，
  对每个参数张量做检验，返回 `per_param` 明细；
- `experiments/exp2_grad_check.py` 覆盖 16 个算子 + 1 个 MLP；
  实测 17 项全部通过，全局最大相对误差 **1.361e-7**（tanh，仍在 1e-5 阈值内）；
- 报告自动写入 `outputs/exp2/梯度检验报告.md`。

### 5.3 扩展③ 异常训练分析

| 实验 | 设计 | 实测现象 |
|---|---|---|
| 过拟合 | 60 训练/90 验证，MLP 4-128-128-3，三组：无正则 / L2 / Dropout+早停 | 无正则：train 0.0077 / val 0.1677；Dropout+ES：val 0.1004，第 277 轮早停 |
| 梯度消失 | 8 层 Linear(32,32)，Sigmoid+normal(0.8) vs ReLU+He；初始化时测逐层梯度 | 输入/输出梯度比：Sigmoid **0.005**，ReLU **0.118**，差约 24 倍 |
| 梯度爆炸 | init_std=0.3 + lr=0.1，8 层 ReLU；无裁剪 vs 全局范数裁剪 1.0 | 无裁剪第 4 轮 NaN；裁剪后 34.25 → **0.648** |
| 学习率震荡 | 线性回归 lr ∈ {1e-4, 1e-2, 1.0} | 1e-4 几乎不降；1e-2 平滑降到 0.235；1.0 发散到 3.2e70 |

每张图配中文标注，`outputs/exp3/分析结论.md` 按
「现象描述 / 原因分析 / 解决方法 / 实验观察」四段式撰写。

### 5.4 扩展④ 数据预处理模块

- `standard_scale/minmax_scale/apply_scale`：统计量仅来自训练集，
  用同一组统计量变换验证/测试集，避免数据泄漏；
- `one_hot`：整型标签 → one-hot；
- `train_test_split(stratify=y)`：分层抽样保持类别比例；
- `DataLoader`：乱序分批，可固定种子复现；
- `load_mnist`：torchvision → 官方镜像 urllib → 本地缓存三级降级；
  `random_shift_images`：整数像素循环平移，作为轻量数据增强；
- 演示脚本输出箱线图、编码表、分布对比、像素统计、增强网格。

### 5.5 扩展⑤ 框架优化功能

- **动量 MBGD**：`v = μv + g`，`θ -= lr·v`，抑制震荡、加速穿越平坦区；
- **Dropout**：训练态 `mask=(rand>p)/(1-p)`（inverted dropout，评估态恒等）；
- **L2 正则**：`λ·Σ‖W‖²/2` 加入损失，梯度 `λW`；
- **EarlyStopping**：连续 `patience` 轮验证损失无改善（> `min_delta`）则停止；
- **LRScheduler**：`step` 阶梯衰减与 `plateau` 自适应衰减，`min_lr` 下限；
- **模型持久化**：`np.savez` 按参数名保存，`load_model` 原地对号加载；
  演示脚本断言保存前后预测 `max_diff == 0`。

## 六、测试策略与结果

### 6.1 三层测试

1. **算子级**：形状测试 + 与朴素实现逐元素对拍 + 中心差分数值梯度；
2. **模型级**：小 MLP/小 CNN 全参数梯度检验；训练损失必须显著下降；
3. **任务级**：线性/逻辑/鸢尾/MNIST/DonkeyCar 的指标验收，以及与 PyTorch 的对照。

### 6.3 与 PyTorch 的差异解释

- 准确率差 0.2 个百分点：初始化随机性、数据打乱顺序不同，属于正常波动；
- 耗时差约 7.6 倍：numpy 逐算子解释执行 + float64 + 无 cuDNN/多线程融合，
  而 PyTorch 使用 C++ 后端与 MKL 优化。若把 MiniFlows 的 dtype 改为 float32
  并减少 Python 层调度，可进一步缩小差距，但会牺牲梯度检验精度。

## 七、可扩展点

1. **新算子**：在 `ops.py` 写前向 + 反向闭包，`_bind(out,[a,b],'Name')` 即可；
2. **新层**：继承 `Layer`，实现 `forward/params/named_params`；
3. **新优化器**：继承 `Optimizer`，实现 `step()`；
4. **新任务**：用 `Sequential` 组合层，`Trainer` 传入 `task='classification'/'regression'`；
5. **批量归一化/残差连接**：均可作为新的 `Layer` 与算子加入，不影响现有 API。
