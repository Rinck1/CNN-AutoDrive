## 1. 文件定位

四类异常训练现象的可复现实验：

1. 过拟合；
2. 梯度消失；
3. 梯度爆炸 + 梯度裁剪；
4. 学习率震荡。

每个实验都有对照、图和中文分析，最后写 `outputs/exp3/分析结论.md`。

## 3. 逐段讲解

### 3.1 过拟合

- 60 训练 / 90 验证，MLP 4-128-128-3；
- 三组：无正则 / L2(1e-3) / Dropout(0.3)+EarlyStopping；
- 每 5 轮记录验证损失；
- 结果：无正则 train 0.0077 / val 0.1677；Dropout+ES val 0.1004；
- 结论要谨慎：验证曲线有波动，不能只说“回升”。

### 3.2 梯度消失（关键：初始化时测量）

- 8 层 Linear(32,32)；
- Sigmoid+normal(0.8) vs ReLU+He；
- **训练开始前**做一次反向，记录逐层 W 梯度范数；
- 以输出层归一化，输入/输出比：
  - Sigmoid 0.005（衰减约 200 倍）；
  - ReLU 0.118（同量级）；
- 训练后同口径比值作为补充，不用于主要结论。

### 3.3 梯度爆炸 + 裁剪

- init_std=0.3，lr=0.1，8 层 ReLU；
- 无裁剪：第 4 轮 NaN；
- 裁剪：全局范数 ≤1，损失 34.25 → 0.648；
- 裁剪位置必须在 `backward` 之后、`step` 之前；
- 图 2×2：损失/梯度范数 × 无裁剪/裁剪。

### 3.4 学习率震荡

- 线性回归 `y=4x+2+noise`；
- lr=1e-4：150 轮仅 7.43→6.95；
- lr=1e-2：降到 0.235；
- lr=1.0：发散到 3.2e70；
- 用 symlog 显示跨数量级曲线。

## 5. 易错点

1. 梯度消失必须在初始化时测，训练后测不典型；
2. 梯度爆炸实验参数要标定（init_std/lr），否则要么不炸要么全程 NaN；
3. 学习率 1.0 是“发散”，不是“震荡”，表述要准确；
4. 过拟合结论不要过度解读验证曲线噪声；
5. 裁剪阈值要与图标题一致（max_norm=1）。
