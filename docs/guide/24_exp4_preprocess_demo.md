# `experiments/exp4_preprocess_demo.py` 阅读指南

> 前置：`data.py` ｜ 难度：★★ ｜ 建议 30 分钟 ｜ 扩展④

## 1. 文件定位

把数据预处理模块的五个功能做成可视化对比：

1. 鸢尾花标准化前后箱线图；
2. one-hot 编码表；
3. 分层划分前后类别分布；
4. MNIST 归一化前后像素统计；
5. 随机平移增强前后对比。

## 2. 结构速览

| 符号/行号 | 作用 |

| `sec1_iris_standardize` (50) | 箱线图 + 均值/方差 |

| `sec3_stratified_split` (132) | 随机划分 vs 分层划分 |
| `sec4_mnist_stats` (180) | 像素均值/方差/最值 |

| `__main__` | 依次执行五节 |

## 3. 逐段讲解

### 3.1 标准化

- 原始四维特征量纲差异大（花萼长度 4~8，花瓣宽度 0.1~2.5）；
- z-score 后每维均值≈0、方差≈1；
- 箱线图左右对比，直观看到尺度统一。

### 3.2 one-hot

用一个小型鸢尾花样本构造表格：整数标签 → `[1,0,0]` 等。
说明 CrossEntropy 需要整型标签，one-hot 只用于分析/其他损失。

### 3.3 分层划分

对比：

- 完全随机划分：测试集类别比例可能偏（如 0.422/0.289/0.289）；
- `stratify=y`：严格保持 1/3、1/3、1/3。

这是“为什么分类任务要分层”的直接证据。

### 3.4 MNIST 像素统计

- 归一化前 [0,255]：均值 33.59、方差 6216；
- 归一化后 [0,1]：均值 0.1317、方差 0.0956；
- 说明输入尺度对优化器步长的影响。

### 3.5 平移增强

`random_shift_images(X, max_shift=2)`：

- 每张图随机上下左右平移整数像素；
- 对比增强前后网格；
- 实测质心平均位移约 1.88px。

## 5. 易错点

1. 缩放统计量只能用训练集（本实验为了直观在全集上展示，报告里要说明）；
2. 分层划分在样本极少时可能失败；
3. 平移是循环平移，边界内容会绕回；
4. MNIST 首次运行会下载约 12MB；
5. 图片标题必须用 `set_title`（`axis('off')` 会隐藏 xlabel）。
