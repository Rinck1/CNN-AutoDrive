# `experiments/tune_donkeycar.py` 阅读指南

> 前置：`donkeycar_eval.py`、Trainer、Adam ｜ 难度：★★ ｜ 建议 40 分钟

## 1. 文件定位

DonkeyCar CNN 的调参与消融脚本，三组实验：

- **A 数据增强**：干净 630 vs 3 倍增强（光度 + 平移）；
- **B 优化器/超参**：学习率、L2、batch；
- **C 闭环后处理**：EMA 平滑、转向速率限制。

规模受限：A 2 种子×10 轮；B 2 种子×6 轮；C 复用 A 的 baseline 模型。
**只做方向性判断，不宣称统计显著。**

## 2. 结构速览

| 顺序 | 符号 | 作用 |
|---|---|---|
| 1 | `train_cnn` | 通用训练（可设 lr/L2/batch） |
| 2 | `eval_clean` / `eval_robust` | 干净指标 / 11 种扰动 |
| 3 | `make_augmented` | 干净 + 光度 + 平移 3 倍数据 |
| 4 | `run_augmentation` | A 组实验 + 图 |
| 5 | `run_optimizer` | B 组 5 组超参 + 图 |
| 6 | `EMAWrapper` / `RateLimitWrapper` | 有状态闭环后处理 |
| 7 | `run_control` | C 组闭环对比 + 图 |
| 8 | `write_report` | 中文报告 |

## 3. 逐段讲解

### 3.1 A：数据增强

`make_augmented`：

```python
Xp = clip((X-0.5)*c + 0.5 + b, 0, 1) + N(0,0.02)   # 光度
Xs = random_shift_images(X, max_shift=2)           # 平移
concat([X, Xp, Xs])                                # 3 倍
```

- 只对训练集做，验证/测试保持干净；
- 3 倍数据会让每轮训练时间约翻倍；
- 评估干净 MAE + 11 种扰动，判断“精度换鲁棒性”的取舍。

### 3.2 B：超参

5 组：

- Adam lr=3e-4 / 1e-3 / 3e-3；
- Adam 1e-3 + L2(1e-4)；
- Adam 1e-3 + batch=64。

每组 2 种子、6 轮；记录 MAE/R²/耗时。
6 轮不足，lr=3e-4 可能欠拟合；报告里要结合验证曲线讨论。

### 3.3 C：闭环后处理

- `EMAWrapper`：`s = α*δ + (1-α)*s`，α=0.3/0.5/0.7；
- `RateLimitWrapper`：相邻帧变化 ≤0.2；
- 复用 A 的 baseline 模型，避免重复训练；
- 12 条赛道（6 同分布 + 4 分布外 + 2 极端）；
- 指标：成功率、最大偏差均值、P95。

后处理不是模型精度提升，只是控制层平滑；α 太大会滞后，极端赛道仍会失败。

## 4. 产物

`outputs/tuning/`：

- `调参报告.md`；
- `调参结果.json`；
- `增强对比.png`、`优化器对比.png`、`控制后处理.png`。

## 5. 易错点

1. 增强只作用于训练集，不能污染验证/测试；
2. 2 种子、6~10 轮的差异不能当最终结论；
3. EMA 状态要在每条赛道开始时重置（当前每个 wrapper 每条赛道新建）；
4. 速率限制可能让连续弯道跟不上；
5. 闭环成功判据仍是 |dev|≤10px，不是最终偏差。
