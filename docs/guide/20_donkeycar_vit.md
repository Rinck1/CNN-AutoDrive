# `applications/donkeycar_vit.py` 阅读指南

> 前置：`transformer.py`、`donkeycar_eval.py` ｜ 难度：★★★ ｜ 建议 90 分钟 ｜ 对比重点

## 1. 文件定位

DonkeyCar 的 ViT 版本：用自研 ViT 替代 CNN，**与 CNN 使用完全相同的协议**，
对比精度、鲁棒性、闭环、成本，并可视化 [CLS] 注意力。

## 3. 逐段讲解

### 3.1 模型

```python
build_vit(img_size=64, patch_size=8, dim=48, depth=2,
          heads=4, mlp_ratio=2)
```

- 64 个 patch + [CLS]；
- 44,353 参数，与 CNN 44,426 基本对齐；
- 输出 `(N,1)`，Tanh 到 [-1,1]。

### 3.2 训练协议

- 900 样本，70/15/15；
- 5 个种子，12 轮，Adam lr=1e-3，batch=32；
- 测试集不参与训练/早停/选模型；
- 平均训练 52.1s/模型（CNN 5.4s）。

### 3.3 结果

| 指标 | ViT | CNN |
|---|---|---|
| 开环 MAE | **0.0520±0.0051** | 0.0534±0.0069 |
| R² | 0.974 | 0.973 |
| 同分布闭环 | 100%，4.29px | 100%，2.90px |
| 分布外闭环 | 100%，7.06px | 100%，5.75px |
| 极端闭环 | 0%，25.72px | 0%，20.69px |
| 单帧 | 6.88ms | 约 0.5ms |
| 训练/模型 | 52.1s | 5.4s |

**统计口径**：MAE 差 0.0014，小于标准差 0.0051/0.0069，
不能宣称 ViT 优于 CNN，只能视为同一水平。

### 3.4 鲁棒性（关键短板）

| 扰动 | ViT | CNN |
|---|---|---|
| 亮度 -0.2 | **0.5385** | 0.0824 |
| 对比度 ×1.3 | **0.4386** | 0.1128 |
| 底部遮挡 | **0.5354** | 0.0885 |
| 中心遮挡 | **0.3346** | 0.1054 |
| 模糊 3×3 | 0.1001 | 0.1408（ViT 更好） |

原因：缺少卷积的局部性/平移等变先验、训练样本少、无光度增强。

### 3.5 注意力图

`plot_attention`：

1. 选 4 张真值从最小到最大的测试图；
2. 前向一次，取第 1 个 block 的 `last_attn`；
3. 对 4 个头取平均，取 CLS 查询行（去掉 CLS 列）→ 64 个 patch 权重；
4. reshape 成 8×8，jet 热力图叠加在原图上。

**必须说明**：这是“原始注意力示意”，不是因果解释。诊断显示：

- block1 归一化熵约 0.79，block2 约 0.90（接近均匀）；
- 头平均 top-1 仅 0.047（均匀=0.0156）；
- 注意力质心列与转向相关约 0；
- 消融成均匀注意力后 MAE 从 0.045 崩到 0.34 → 机制有用，但热图不可解释。

## 4. 调用关系

复用 `donkeycar.generate_track_dataset` 与 `donkeycar_eval` 的
`split_indices/regression_metrics/perturb_images/closed_loop_run/sample_tracks`；
读取 CNN 的 `outputs/donkeycar/donkeycar_测试结果.json` 做对比。

## 5. 易错点

1. **公平性**：协议必须与 CNN 完全一致，否则对比无效；
2. **统计显著性**：0.0014 的差距不能吹成“ViT 更好”；
3. **鲁棒性**：必须如实报告 ViT 的光照/遮挡短板；
4. **注意力图**：不能写“模型主要关注这里”；
5. **训练成本**：52s vs 5.4s，报告里要写清。
