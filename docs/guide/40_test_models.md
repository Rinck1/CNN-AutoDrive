# `tests/test_models.py` 阅读指南

> 前置：`classic_cnn.py`、`profiler.py` ｜ 难度：★★ ｜ 建议 20 分钟

## 1. 文件定位

经典模型、分组/深度卷积、规模分析口径的测试。

## 2. 结构速览

| 顺序 | 测试 | 检查什么 |
|---|---|---|
| 1 | `test_grouped_conv` | 分组卷积 == 逐组普通卷积拼接 |
| 2 | `test_depthwise_conv` | 深度卷积 == 逐通道卷积；梯度中心差分 |
| 3 | `test_classic_models` | VGG11/MobileNet 输出形状、参数量、可分离卷积省参 |
| 4 | `test_profiler` | FLOPs 与手算一致、激活内存 > 0 |

## 3. 逐段讲解

### 3.1 分组卷积对拍

```python
got = conv2d_groups(x, W, groups=2)
ref = concat([conv2d(x[:, 0:2], W[0:2]), conv2d(x[:, 2:4], W[2:4])], axis=1)
assert max|got-ref| < 1e-12
```

差值为 0，说明分组实现与前向切片完全一致。

### 3.2 深度卷积

- 与“逐通道单通道卷积”对比，差 8.9e-16（浮点误差）；
- 梯度检验：固定输出权重 `Wo`，对 x/W/b 三个输入一起检验，`max_rel≈2.5e-8`。

**注意**：数值梯度测试里的输出权重必须**在 lambda 外固定**，
否则每次调用重新随机，数值梯度会变成噪声（本项目踩过这个坑）。

### 3.3 经典模型

- VGG11 输出 `(2,10)`、参数量约 20.9 万；
- MobileNet(w=0.25) 输出 `(2,10)`、约 21.8 万；
- 可分离卷积 32→64 参数 2,432 vs 标准 18,496（0.13×），与理论 `1/F+1/9` 吻合。

### 3.4 profiler 口径

```
FLOPs = conv1 4608 + relu 256 + conv2 9216 + fc 2560 = 16,640
```
与 `count_flops` 完全一致；VGG 激活内存 3.69 MB > 0。

## 4. 运行

```bash
python tests/test_models.py
```

末尾输出 `✓ 模型与规模分析全部测试通过`。

## 5. 易错点

1. 分组卷积的 `groups` 必须整除通道数；
2. 深度卷积要求 `W.shape[1]==1` 且 `W.shape[0]==C`；
3. FLOPs 手算别忘了逐元素算子（ReLU 按 1 FLOP/元素）；
4. 激活内存测试依赖模型的层可遍历（`_iter_layers`）。
